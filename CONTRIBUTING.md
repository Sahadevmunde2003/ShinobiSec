# Contributing to ShinobiSec

Thanks for contributing.

## Development

1. Fork or clone the repository.
2. Create a focused branch for your change.
3. Install dependencies with `pip install -r requirements.txt`.
4. Test the Flask application locally.
5. Keep security checks authorized, defensive, and non-destructive.
6. Submit a pull request with a clear description of the change.

## Scope

Changes should preserve the project's educational cybersecurity purpose and avoid functionality intended for unauthorized access, exploitation, credential theft, persistence, or destructive activity.
